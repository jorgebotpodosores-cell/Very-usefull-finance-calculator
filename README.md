# 🇪🇸 Spanish Personal Finance & Tax Calculator (CLI Logic)

I built this Python command-line utility at 14 years old to practice algorithmic logic, code structure, and financial modeling. 

Instead of using basic, static calculations, this script dynamically maps out multi-decade compound interest and accurately routes income through Spain's progressive tax brackets using custom data structures.


---

## 🚀 Available Commands
While this is a backend logic prototype, it fully supports the following terminal targets:
* `compound`: Simulates multi-year recurring investments.
* `IRPF`: Models gross-to-net salary reductions including employee social security (4.7%).
* `gains`: Applies progressive Spanish savings tax to investment profits.
* `freedom`: Calculates the net asset target needed to achieve a 4% Safe Withdrawal Rate.
* `emergency`: Scores financial runway length based on fixed monthly outflows.
* `savings`: Simulates a savings account over time and money that could have been gained investing.
